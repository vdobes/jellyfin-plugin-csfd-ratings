# Security policy

## Supported versions

Security fixes are provided for the latest published plugin version compatible with the current supported Jellyfin release.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form in the repository Security tab. This creates a private security advisory and keeps sensitive details out of public issues.

Include:

- affected plugin and Jellyfin versions;
- installation type and relevant configuration with secrets removed;
- reproduction steps and expected impact;
- suggested remediation, if known.

Do not include API keys, access tokens, private URLs, personal media paths, or unredacted logs. You should receive an acknowledgement within seven days. A public advisory and fix will be coordinated after the issue is understood.

General bugs and support questions belong in public GitHub Issues.
