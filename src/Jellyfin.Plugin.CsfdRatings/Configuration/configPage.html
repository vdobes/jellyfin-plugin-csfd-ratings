K ručnímu párování

Zkopíruj ČSFD ID kandidáta a vlož ho do pole níže ve tvaru ItemId = csfdId, nebo ho zadej přímo v editoru metadat filmu (pole ČSFD).

Nastavení

Když je vypnuto, neběží provider ani úlohy.
Do logu se zapíše, co by se změnilo, ale databáze zůstane nedotčená. Doporučeno pro první běh.
node-csfd-api ve vnitřní Docker síti, například http://csfd-api:3000. Přednostně ji nech ve vnitřní síti; při zveřejnění vždy nastav API klíč.
Vyplň jen když má služba csfd-api nastavenou proměnnou API_KEY. Posílá se v hlavičce x-api-key. Prázdné = sidecar běží bez autentizace.
Výchozí 2000. Níž nechoď.
Strop pro klouzavé okno sedmi dní. Po vyčerpání se běh ukončí a hodnocení zůstanou beze změny. 0 = bez limitu. Výchozí 2000.
Po uplynutí se hodnocení načte znovu. Výchozí 90 dní.
0 = bez omezení. Pro první backfill zkus třeba 20.
Bez shody režiséra se tolerance nepoužije. Nejednoznačné případy skončí vždy jako „k ručnímu párování“.
Původní CommunityRating se uloží, aby ho šlo vrátit tlačítkem „Obnovit původní hodnocení“. Vypnutím se přepis stane nevratným.
Spustí se pár minut po dokončení skenu knihovny.
Jeden pár na řádek: ItemId = csfdId. Přijme i celou ČSFD URL. Řádky začínající # jsou poznámky. Má přednost před vším ostatním.
